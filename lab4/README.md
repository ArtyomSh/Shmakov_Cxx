##  LAB_4

### Задание:
Задание: разработать шаблонные классы для хранения разреженных вектора и 2D матрицы для чего:
* Предложить структуры данных для хранения значений исходных векторов и матриц;
* Реализовать набор унарных и бинарных операций для вектора и матриц;
* Реализовать поэлементные операции для элементов векторов и матриц — арифметические операции со скалярной величиной, поэлементное возведение в степень.
* Провести сравнение скоростей обработки предложенного вами способа хранения и обработки разреженных матриц и выполнение тех же действий над векторами и матрицами, хранящимся с помощью стандартного контейнера vector.

### Запуск:

``` bash
# build project
make clean && make

# run program
./main
```

### Решение
**Для разреженного вектора был реализованы следующий функционал (sparseVector.cpp):**
- Сложение с другим р-м вектором  той же длины;
```
SparseVector<T> operator+(const SparseVector<T> &other) {...}
```
- Разность двух р-х векторов одной длины;
```
SparseVector<T> operator-(const SparseVector<T> &other) {...}
```
- Умножение на скаляр;
```
SparseVector<T> operator*(const T &scalar) {...}
```
- Скалярное произведение;
```
T dot(const SparseVector<T> &other) {...}
```
- Сложение со скаляром (поэлеметное сложение);
```
SparseVector<T> operator+(const T &scalar) const {...}
```
- Вычитание скаляра (поэлементное);
```
SparseVector<T> operator-(const T &scalar) const {...}
```
- Деление вектора на скаляр (поэлементное);
```
SparseVector<T> operator/(const T &scalar) const {...}
```
- Поэлементное возведение в степень;
```
SparseVector<T> elementWisePow(const T &exponent) const {...}
```

**Для разреженной матрицы (sparseMatrix.cpp)**
- Транспонирование;
```
SparseMatrix<T> transpose() {...}
```
- Возведение матрицы в степень (для не квадратных матриц будет возвращаться ошибка);
```
static SparseMatrix<T> pow(const SparseMatrix<T> &mat, int n) {...}
```
- Сложение двух р. матриц;
```
SparseMatrix<T> operator+(const SparseMatrix<T> &other) {...}
```
- Произведение р. матриц;
```
SparseMatrix<T> operator*(const SparseMatrix<T> &other) {...}
```
- Умножение на скаляр;
```
SparseMatrix<T> operator*(const T &scalar) {...}
```
- Умножение р. матрицы на р. вектор;
```
SparseVector<T> operator*(const SparseVector<T> &vec) {...}
```
- Сложение со скаляром;
```
SparseMatrix<T> operator+(const T &scalar) const {...}
```
- Вычитание скаляра;
```
SparseMatrix<T> operator-(const T &scalar) const {...}
```
- Деление на скаляр;
```
SparseMatrix<T> operator/(const T &scalar) const {...}
```
- Поэлементное возведение в степень;
```
SparseMatrix<T> elementWisePow(const T &exponent) const {...}
```
