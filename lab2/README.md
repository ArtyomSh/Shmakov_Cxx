##  LAB_2

### Задание:
* Спроектировать класс, реализующий хранение данных, связанных с экземпляром класса в динамической памяти. В моем случае, это класс Box, в котором хранится число и его строковое представление;
* Для класса необходимо реализовать все необходимые конструкторы, включая конструкторы копирования и перемещения, а также деструктор. Все конструкторы и деструктор должны выводить логи, сообщающие о вызове; 
* Аналогично для перегрузки операции присваивания (два варианта: без перемещения и с перемещением). 

### Запуск:

### Класс Box:
- PRIVATE:
    - **counter**: статический счетчик, для генерации уникальных idx.
    - **idx**: уникальный идентификатор экземпляра класса;
    - **number**: хранящееся в объекте число;
    - **interpretation**: интерпретация числа в виде строки;
    - **numberToString**: вспомогательная функция, для получения строчной интерпретации входного числа.
- PUBLIC:
    - **Box()** - конструктор по умолчанию, вызываемый при отсутствии входного параметра;
    - **Box(int input)** - конструктор с входным параметром;
    - **Box(const Box &other);** - конструктор копирования;
    - **Box(Box &&other)** - конструктор перемещения;
    - **Box &operator=(const Box &other)** - оператор присванивания (копированием);
    - **Box &operator=(Box &&other)** - оператор присваивания (перемещением);
    - **~Box()** - деструктор;
    - **int getIdx() const** - гетер для получения индекса объекта;
    - **int getNumber() const** - гетер для получения числа, хранящегося в объекте;
    - **const char *getInterpretation() const** - гетер для получения строковй интерпретации числа;
    - **std::string getBoxInfo() const** - гетер для получения развернутого сообщения - характеристики конкретного объекта класса;
